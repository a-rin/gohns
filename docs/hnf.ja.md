# gohns が読む HNF の形式

[English](hnf.md) | 日本語

gohns は、HNF のうち、よく使う部分だけを実装していて、すべてではありません。この
文書は、`hns/render/render.go` が読むものを書いたもので、`sample/diary` の日記で確かめ
ました。ここにないコマンドは、ページに `ERROR NAME is not implemented` が出ます。

HNF の仕様は、hns 2.20 のドキュメントの
[hnf の記述方法](https://web.archive.org/web/20230512122453/http://www.h14m.org/docs/hnf-j.html)
のページです。gohns が仕様に従っていない点は、
[元との違い](#元との違い)を見てください。

## ファイル

1 日の日記は、`DiaryDir/YYYY/dYYYYMMDD.hnf` です。ファイルの文字コードは、設定の
`DiaryCode` です。ファイルの先頭の UTF-8 のバイトオーダーマークは受け付けます。
1 行は 1 MB まで書けます。

## 行

- 最初の `OK` の行より前の文字は、無視します。日記は、その後から始まります。
- 空行は無視します。行末の空白は取り除きます。
- `!` で始まる行はコメントです。テンプレート `Comment`(サンプルでは
  `<!--{{text}}-->`)で書き出されるので、ページの HTML ソースに出ます。メモを
  ページに出したくないサイトは、テンプレート `Comment` を空にします。`!#` で始まる行は、
  書き出しません。
- `~` で終わる行は、`~` を取り除いて、テンプレート `TextLn`(サンプルでは `<br>` を
  付けます)で書き出します。それ以外の行は、`Text` で書き出します。
- 大文字の単語だけの行、または、大文字の単語、空白、続きの文字の行は、コマンドです:
  `NEW タイトル`。`/` で始まる単語は、何かを閉じます: `/UL`。
  **文章の行を、このような単語で始めてはいけません。** たとえば `A new day` は、`A` が
  コマンドとして読まれて、`ERROR A is not implemented` になります。`The` のように
  小文字を含む単語は、文章です。

## コマンド

1 日は、最初の `NEW` か `LNEW` から始まります。

| コマンド | 引数 | 書き出すもの |
|---|---|---|
| `CAT` | 名前(空白で区切る) | 次の `NEW` か `LNEW` のカテゴリを設定する。クエリの `CAT=name` は、このカテゴリの節だけを表示する |
| `NEW` | タイトル | セクション |
| `LNEW` | `uri` タイトル | タイトルがリンクのセクション |
| `SUB`、`/SUB` | タイトル | サブ・セクション。`/SUB` で閉じる |
| `LSUB` | `uri` タイトル | タイトルがリンクのサブ・セクション |
| `P`、`/P` | | 段落 |
| `LINK` | `uri` 文章 | リンク |
| `URL` | `uri` 文章 | `uri` を表示するリンク。テンプレート `Url` で書き出す。そのテンプレートがない設定では `Link` を使う |
| `STRIKE` | 文章 | 取り消し線の文章 |
| `LSTRIKE` | `uri` 文章 | 取り消し線の文章のリンク |
| `STRONG` | 文章 | 強調した文章 |
| `SPAN` | クラス 文章 | そのクラスの span |
| `CITE`、`/CITE` | | 引用 |
| `PRE`、`/PRE` | | 整形済みテキスト |
| `UL`、`/UL`、`OL`、`/OL` | | リスト |
| `LI` | 文章 | リストの項目 |
| `DL`、`/DL` | | 定義リスト |
| `DT`、`DD` | 文章 | 用語、説明 |
| `DIV`、`/DIV` | クラス | そのクラスのブロック |
| `FN`、`/FN` | | 間の行が脚注で、セクションの末尾に書き出す |
| `IMG` | [`r`\|`l`\|`n`] `uri` [alt] | 画像。`r`、`l`、`n` は元の位置の指定で、右、左、なし。位置の語がない `IMG uri [alt]` も使える |
| `LIMG` | リンクの `uri` [`r`\|`l`\|`n`] 画像の `uri` [alt] | リンクになった画像。位置の指定は同じ |
| `PHOTO` | id 文章 | テンプレート `Photo`(サンプルにはない) |

`LINK`、`LSTRIKE`、`LNEW`、`LSUB`、`LIMG` は引数が必要です。ないと、ページに
`ERROR "LINK" must have 2 param.` のように出ます。知らないコマンドは
`ERROR NAME is not implemented` になります。

コマンドが何を書き出すかは、設定の同じ名前のテンプレート(`New`、`Link`、`Ul`、
`_Ul` など)で決まるので、そこで変えられます。

## 元との違い

上の仕様と突き合わせて確かめたもので、元の hns を動かして確かめたものではありません。

- `IMG` と `LIMG` は、元の書き方 `IMG {r|l|n} ファイル 説明` と
  `LIMG url {r|l|n} ファイル 説明` を読み、位置の語がない書き方 `IMG ファイル [alt]` と
  `LIMG url ファイル [alt]` も読みます。位置は `align` 属性としては書き出しません。
  テンプレートが変数 `align`(`right`、`left`、空)を受け取り、サンプルは、クラス
  `align-right` か `align-left` を付けます。
- `!` は、テンプレート `Comment` で書き出し、空にできます。元は、いつも HTML の
  コメントを書き出します。
- 元の次のコマンドは、実装していません: `RLNEW`、`RLSUB`、`RLINK`、`GRP`、`FONT`、
  `MARK`、`ALIAS`、`RT` と `/RT`、`LINK` などの URL の特別な書き方(`#YYYYMMDD`、
  `ISBN:`、`CD:` など)。`OK` より前のヘッダ部の変数は、無視します。
- `PHOTO` と `/SUB` は gohns にあり、そのページにはありません。

元の仕様には、行頭の大文字の単語は、今はコマンドでなくても、将来コマンドになる
かもしれない、という注意もあります。

## 例

```
OK
CAT tech
NEW The title
The line of text.~
Another line.
SUB A sub-section
LINK https://example.com/ a link
UL
LI first
LI second
/UL
! this line is a comment
```

`SUB` の行はコマンドなので、その後ろの `A sub-section` は引数で、文章ではありません。
`A ` で始まる文章の行は、コマンド `A` として読まれます。
